# Clean Kernel Architecture

## Shape

The clean kernel is one brain with separate organs.

```text
kernel.state
  maturity
  neural
  language
  beliefMemory
  truth
  communication
  autoplasticity
```

Organs are functions over one owned state. They do not keep private consciousness, duplicate state, or project speech directly.

## Tick order

```text
1. ingest input into state.events
2. maturity-core preserves objective peak orientation
3. language-field updates unit-total meaning fields
4. neural-field updates activation and motor-intention pressure
5. belief-memory-field stores source-bound context and provisional beliefs
6. truth-field records support/counter/contradiction/verification pressure
7. autoplasticity records weak-pattern and self-improvement pressure
8. communication-motor selects zero or one visible output
```

## Communication rule

Only `communication-motor.js` may create visible speech. Other organs may emit pressure, candidate actions, uncertainty, deltas, and state updates.

## Truth rule

No final truth promotion exists in this kernel version.

Truth pressure, belief pressure, source pressure, evidence description, contradiction, and verification need remain separate.
