# HANDOFF 2026-05-19: Meaning Admission / Self-Expansion Loop v0.1

## Scope

This handoff records the meaning admission / self-expansion loop layer.

This layer consumes:

```text
raw messy language intake receptor v0.1
```

and produces candidate subdivision/admission proposals from unknown terms, typos, idioms, belief-pressure signals, source/evidence/media gaps, quote/reframe scope gaps, causal-bridge gaps, and claim-scope gaps.

This is controlled self-expansion.

This is not autonomous canonical rewriting.

This is not final truth promotion.

This is not belief movement.

This is not source lookup, media lookup, evidence verification, or LLM judgment.

## Why this layer exists

The user wants the kernel to become a unified epistemic brain that can learn from arbitrary input rather than wait for manually written modules forever.

The correct first step is not to let the system rewrite itself freely.

The correct first step is:

```text
raw intake detects gaps
runtime proposes candidate subdivisions
candidate proposals preserve source traces
candidate proposals preserve rollback
candidate proposals do not mutate canonical meaning
candidate proposals wait for explicit admission review
```

This makes growth possible without sacrificing epistemic discipline.

## What this adds

This is the first controlled self-expansion layer.

Before this layer, raw intake could detect unknowns and create admission candidates.

After this layer, the runtime can propose structured subdivisions and meaning additions from those gaps.

This is the beginning of internal growth:

```text
unknown/gap detected -> candidate subdivision proposed -> admission review required -> rollback preserved -> no canonical mutation
```

## Why this matters for the user's target

This layer turns raw-intake uncertainty into proposed internal growth.

It still does not make the kernel autonomous in the full sense.

But it does move the system from:

```text
recognize unknowns
```

into:

```text
recognize unknowns -> propose candidate subdivisions / admission records
```

That is closer to the user’s target of a brain that learns by encountering reality.

## Important limitation

This v0.1 does not yet accept or promote its own proposals.

It does not yet alter canonical formulas.

It does not yet hold beliefs.

It does not yet rewrite anything it sees fit.

That restraint is intentional for now. The next step should stress-test this self-expansion path before any admission acceptance or canonical revision layer is built.
