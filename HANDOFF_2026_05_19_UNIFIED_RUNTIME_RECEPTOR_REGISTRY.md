# HANDOFF 2026-05-19: Unified Runtime Receptor Registry v0.1

## Scope

This handoff records the unified runtime receptor registry layer.

This layer consumes:

```text
dossier packet stress benchmark v0.1
```

and produces a unified brain-state runtime where existing deterministic capabilities are registered as receptors/operators inside one runtime.

This layer is not a final truth authority.

This layer is not a raw messy language intake parser yet.

This layer is the architectural consolidation step required before raw messy intake should be built.

## Why this layer exists

The user corrected the architecture:

```text
The brain itself should be 1.
Modules should be receptors/operators inside 1, not side systems operating beside it.
Structured packets are a safety scaffold, not the final intake model.
The kernel should eventually handle arbitrary text, claims, meanings, beliefs, typos, fragments, and messy input through one unified objective language runtime.
```

This layer turns that correction into code.

Wrong architecture:

```text
raw text -> external parser/filter -> kernel
```

Correct direction:

```text
raw event -> unified runtime -> receptors activate -> candidate interpretations/packets/relations/pressure/admission candidates form inside the same brain state
```

## What this adds

This is the architectural consolidation layer.

Before this layer, the kernel mostly behaved as a set of tested modules calling other modules.

After this layer, those capabilities can be represented as receptors/operators inside one runtime state.

This matters because future raw intake should not become another side parser.

Future intake should be:

```text
raw event enters unified runtime
receptors activate inside 1
candidate meanings/packets/relations/pressures/admissions form inside 1
truth and belief remain controlled by future promotion criteria
```
